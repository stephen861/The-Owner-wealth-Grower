# FGW Leasing Agent: Render setup (owner steps)

Everything below happens in **your** accounts. You type every key and password
yourself; nobody else needs them. The agent stays in dry run (`LEASING_LIVE=false`)
the whole time, so it can only text the test numbers you list.

## Before you start
1. **Twilio warning.** Log in to the Twilio Console and clear the "suspected account
   takeover" notice (check users, API keys and recent activity). Don't connect a number
   until it's gone.
2. Have these ready: a Claude API key (console.anthropic.com > API keys), your Twilio
   Account SID, Auth Token and texting number, a staff password (12+ characters),
   the office phone you want shown to prospects, and your cell number.

## Create the service (about 10 minutes)
1. Go to render.com and sign up or log in. Connect GitHub when it asks, and allow
   the repo `stephen861/The-Owner-wealth-Grower`.
2. Click **New > Blueprint**, pick that repo, and pick the branch
   `leasing-no-screening-staff-login`. Render reads `render.yaml` and shows one web
   service, `fgw-leasing`, in Ohio with a 1 GB disk. It's a paid instance (a disk needs one).
3. Render asks for each value once. Type them in:
   | Setting | What to type |
   |---|---|
   | `STAFF_PASSWORD` | the staff password (12+ characters) |
   | `ANTHROPIC_API_KEY` | your Claude API key |
   | `TWILIO_ACCOUNT_SID` | starts with `AC` |
   | `TWILIO_AUTH_TOKEN` | from the Twilio Console |
   | `TWILIO_FROM_NUMBER` | texting number like `+16145550123` |
   | `PUBLIC_BASE_URL` | `https://fgw-leasing.onrender.com` (fix it in step 5 if Render shows a different address) |
   | `FGW_OFFICE_PHONE` | the office number prospects should call |
   | `LEASING_TEST_NUMBERS` | your cell like `+16145550123` (comma-separate more) |

   `LEASING_SESSION_SECRET` is generated by Render. `LEASING_LIVE` is preset to `false`.
4. Click **Apply** and wait for the deploy to say **Live**.
5. Copy the service address from the top of the Render page. If it isn't
   `https://fgw-leasing.onrender.com`, open **Environment**, set `PUBLIC_BASE_URL` to the
   real address, and save (Render redeploys).
6. Open `<address>/leasing`, log in with the staff password. You should see an empty inbox.

## Add the listing
In the inbox, open **Properties & units** and add 48 S Richardson Ave
(program Market, accepts vouchers, Columbus OH, office phone and hours, application link,
fee, policies), then add unit 48: 2 bed, 1 bath, $1,400, Market, available.

## Connect Twilio (test mode)
In Twilio > Phone Numbers > your number > Messaging, set **A message comes in** to
Webhook, HTTP POST, `<address>/api/leasing/sms`, and save.

From your cell, text the number: "Do you have a 2 bedroom?", "Do I qualify?",
"Can I see it Saturday at 11?", "I need a person", "STOP" then "START".
Every thread shows in `/leasing`. Texts to any other number are held, not sent.

## Go live (only on Stephen's yes)
Render > Environment > set `LEASING_LIVE` to `true` > save. To stop all texting at any
time, set it back to `false`. To pause the AI on one person, open the thread and press
**Take over (pause AI)**.
